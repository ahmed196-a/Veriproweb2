## 🌟 Highlights & Features

- **Strict Adherence to Brand & Theme Guidelines (Pages 25 & 26)**:
  - **Deep Navy** (`#14304F`), **Action Blue** (`#1D4ED8`), **Soft Off-White** (`#F8FAFC`), **Dark Slate** (`#1F2937`), **Cool Grey** (`#475569`), **Light Blue Tint** (`#EAF0FF`).
  - Alternating section rhythm (**White** ⇄ **Deep Navy**).
  - Open-source **Inter** typeface (SIL Open Font License) with compliant typography scale.
  - Mandatory **3px Action Blue focus outline** for WCAG 2.2 Level AA accessibility compliance.
  - High-resolution authentic vector-rendered logos directly extracted from PDF guidelines (both light-surface and navy-surface versions with minimum 160px width and "v" clear space).

- **10 Core Website Sections**:
  1. **Hero & About**: Core pitch, values (*Trusted, Professional, Innovative, Results driven*), US-registered entity details, and interactive Vera AI conversation example.
  2. **VeriPro Software**: Honest status tags (**VeriBook** `EARLY ACCESS`, **VeriBill** `PLANNED`, **VeriHR** `PLANNED`, **Vera** `IN VERIBOOK`) and the 3 software behavior rules.
  3. **Pricing (Standard & Bespoke)**: $10/mo or $100/yr (saves $20/yr), bespoke custom quotes, advisory & delivery matrix, and non-refundable early-access disclosure.
  4. **Placement Referral & Augmentation**: 5% annual pay placement fee calculator, terms table, 3-month attrition protection, and counsel antitrust notice.
  5. **Services (Key Offerings)**: 01 Advisory, 02 AI Automation, 03 Digital Ops & CRM, 04 People & Org.
  6. **Engagement Model**: 4-step framework (*Assess, Advise, Transform, Manage*) + client commitments.
  7. **Solutions by Business Type**: 7 sectors (Salons, Clinics, Law firms, Retailers, Small businesses, Freelancers, Home businesses) with HIPAA and ethics disclaimers.
  8. **FAQ**: Searchable and categorised answers to the 10 questions we hear most.
  9. **Contact & Booking**: 30-min discovery call booking flow, contact credentials, and responsive enquiry form with formatted email dispatch.
  10. **Connection Guides 1 to 5**: Step-by-step playbooks for Booking (`BOOKING_URL` controller), Payments & refunds (Stripe/Square), Vera AI (4 non-switchable rules), Email/SPF/DKIM/CRM, and Hosting.

- **Interactive Sandboxes & Modals**:
  - **Live Vera AI Assistant Sandbox**: Simulates explicit confirmation, HIPAA medical advice refusal, legal advice refusal, refund escalation, and instant `STOP` opt-out.
  - **10-Point Pre-Launch Checklist**: Interactive readiness calculator.
  - **Brand & WCAG Contrast Inspector**: Visual color swatches and measured contrast ratios.
  - **Governance & Legal Hub**: Full verbatim text for Privacy Policy (p.12), Terms of Use (p.13), Security (p.19), Copyright (p.20), Trademark (p.21), Tax (p.23), Disclaimers (p.24), and 18 Open Items (p.27).

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm 9+

### Installation
```bash
git clone https://github.com/ahmed196-a/Veriproweb2.git
cd Veriproweb2
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
